我的空间 / 创作工作台
ComicBrain 负责故事记忆，ComicPerfect 让它成为漫画。交互原型 / 非真实生成

让创作连续，让操作轻一点

这是一份可点击的 UX 设计稿，不连接模型或数据库。系列、章节与封面均为演示，不代表已有 ComicBrain 私有内容。

两条创作路径，一个工作空间

系列：浏览原则与系列设定 → 设计连续剧情 → 人工修改章节 → 生成分镜与漫画。
单篇：输入想法 → 生成分镜 → 人工调整 → 生成漫画。

少确认，但不模糊创作边界

编辑自动保留在本次预览内，不弹保存确认。生成漫画不等于写入正史；仅在用户主动选择“定稿并写入 ComicBrain”时，展示一次明确的影响确认。设计稿不执行该写回。

作品与故事各有自己的版本

已生成漫画留在历史版本中。修改剧情只把当前作品标记为“待重新生成”，不覆盖旧漫画；模型参数、导出与局部重绘放在需要时展开的位置。

将这版故事定稿到 ComicBrain？

生成漫画不会自动改变正史。正式产品中，此操作将记录当前章节决策，并检查人物状态、时间线与后续剧情的影响；旧记录和图像版本会保留。

本次影响范围

当前章节脚本与封面描述、章节状态、相关人物和系列当前状态。若发现冲突，应先展示具体冲突，不静默覆盖。
